# Agent Note: 本地改版移除账号并同步系统剪贴板

Status: implemented

## Problem

手机收到电脑文字后只存入历史，直接粘贴与最近复制提示仍指向旧的系统剪贴板。安卓采集绑定输入法窗口的历史处理和隐私状态，重复文字被历史拒收时不会发送。用户要求移除上游账号系统、剪贴板一键入口和三行数字键盘。

## Decision

移除安卓登录 SDK、账号页面、登录回调和会话 provider 的打包入口；主页提供设置、设备互通、统计和本机工具，不创建匿名账号或访问账号服务。共享源中的兼容类型保留用于非账号功能的编译，云端账号传输层拒绝请求。

局域网使用既有 TLS 协议和加密信任存储，收到认证新事件后写入两端系统剪贴板。安卓用单一采集监听与标签抑制回传，Windows 在同一监听窗口线程写入并记住对应系统序号。事件按 ID 去重，同文的新复制允许发送。安卓开启同步同时启用本地历史，可见 connectedDevice 前台服务保留连接；隐私模式与敏感剪贴板仍不分享。

历史按文字合并、传输按事件去重：Windows 服务保留有限的已接收事件集合，避免新事件替换历史后旧 ID 重试再次写入；安卓加密存储保留最近事件帧。两端在主线程/窗口线程写系统剪贴板前，检查排队期间是否出现更新的本机复制。安卓本机采集使用独立串行队列，保存成功后才标记已处理，TLS 连接不占用采集队列。

键盘工具栏固定保留前部剪贴板入口；原隐藏模式改为精简，仍保留更多、剪贴板和收起键。数字层用 123 / 456 / 789 三行与右侧操作列，0 和小数点在底行。设置页同步说明精简行为，避免显示与实际入口不一致。安卓版本名带 zhuoyiwan-r2，构建号从 3001 增至 3002，使用此前同一签名覆盖安装。

现有笔记审计：[局域网互通](2026-10-12-android-windows-lan-clipboard.md)部分重叠，保留 TLS 与协议选型，该篇的历史独立及进程生命周期方案被本决定取代；上游云剪贴板笔记描述另一套服务，保留供原实现追溯。

## Alternatives considered

只补充历史入口能让旧行为更容易发现，且不覆盖系统剪贴板；但不能满足复制后直接粘贴，因此改为系统剪贴板互通。只在输入法窗口开放时采集不需要常驻通知，但切换应用复制时容易失效，采用用户可停止的前台连接服务。彻底删除所有跨平台账号兼容类型可以缩减更多源码，但会牵动通用社区、翻译与本地设置的类型契约；当前移除安卓可达的登录组件并关闭账号传输。

## Testing

ARM64 assembleFullRelease 与 lintFullRelease 通过。DEX 检查确认不含 Google 登录 SDK、账号页面、登录回调、账号 provider 和云剪贴板控制器；签名证书与上一改版一致，16 KB zipalign 验证通过。

API 35 隔离模拟器与 Windows 生产 OpenSSL TLS 实现互通。Windows 新事件进入 Android 系统剪贴板、最近复制提示点按插入、普通系统粘贴、完整/精简工具栏一次点击历史、数字网格的实际位置及 0–9 点按、Android 本机复制回到 Windows 并获得确认、移除配对和加密状态重载均通过。原 DeviceSmoke 的中文上屏、繁体显示/上屏、删除、密码直接输入及隐藏键盘组字回收通过。KeyboardLayoutSmoke、SplitKeyboardPolicySmoke 和 LAN 协议 26 项拒绝/兼容检查通过。

Windows Server 全部 CTest 通过，覆盖同文新 ID、旧 ID 重传不覆盖新历史和服务收发。原生系统剪贴板的独立 window station 烟测因本执行环境 CreateWindowStation 返回 ERROR_ACCESS_DENIED 未运行，未把它算作通过；普通桌面粘贴仍需安装后的实机验证。工具链烟测草稿保留在 F 盘缓存，不接入日常门禁。

## Consequences

Android 厂商仍可限制后台进程；服务以通知明确可见，系统强停后需重新打开应用。设备互通会替换当前系统剪贴板，历史保留旧文字；接收重试与并发本机复制必须避免重复回放及覆盖更新的本机内容。真实手机省电策略和扫码硬件仍需用户验证。大文件与构建缓存保持在 F 盘。

无需账号即可配对与粘贴，登录 SDK 和账号会话入口不进入安装包。共享账号类型与社区历史源码仍保留，但可达账号传输拒绝请求；若未来恢复任何账号或云服务，必须重新定义本改版的信任与 UI 边界。前台服务增加常驻通知，启用同步时申请通知权限，用户可从通知停止同步。
